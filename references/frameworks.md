# 可填写工作表

## 第1步
写希望观者经历的具体情绪或思考变化及观看场景，不从堆“东方元素”开始。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
选真实或明确虚构的景物、声音、文字与动作，说明各元素为何承载该情绪；情与景建立可解释连接。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
安排近处可见、展开后可见与想象延续的层次，留出有目的的空白，必要信息不隐藏。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
绘制观看或行进顺序、停留点与转折，用疏密、明暗和动静改变节奏；先以小样验证。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
检查元素是否彼此争夺注意，比较具象、节制或混合方案；文化来源与素材许可分别登记。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
输出情景表、路径说明、两种小样及观者反馈，保留未达到的体验；艺术体验不由步骤合规自动产生。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

检查每项形式选择是否连接体验意图及必要信息是否保留；不能衡量艺术价值。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_design_trace.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
